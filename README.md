# openalex-formatter (retired)

**Retired. Do not deploy or edit.** This service ran OpenAlex's works exports (CSV, RIS, BibTeX, WoS plaintext) at
`export.openalex.org` until 2025-12-07. Exports moved to **openalex-users-api** (`formats/`, served at
`user.openalex.org/export/...`), which the website calls today. The Heroku app's database and add-ons were removed on
2026-10-14 (oxjob #1676) and the repository was archived.

Fix export bugs in `ourresearch/openalex-users-api` `formats/`, not here.
